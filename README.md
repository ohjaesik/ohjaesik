# 안녕하세요, 오재식입니다.

컴퓨터공학을 기반으로 AI 시스템, 데이터 분석, 컴퓨터 비전, GPU/NPU 기반 추론 최적화에 관심을 가지고 개발하고 있습니다.  
단순히 모델을 사용하는 것보다, 실제 서비스 환경에서 AI가 어떻게 동작하고 어떤 병목이 발생하는지 분석하는 데 초점을 두고 있습니다.

## 진행 중이거나 경험한 프로젝트

### 교내 코드 아카이브 및 자연어 검색 시스템

교내 수업, 캡스톤디자인, 팀 프로젝트에서 생성되는 코드와 문서를 체계적으로 저장하고 검색할 수 있는 시스템을 개발하고 있습니다.

주요 목표는 다음과 같습니다.

- 과거 프로젝트 코드와 문서를 통합 저장
- README, 코드, 보고서에서 메타데이터 추출
- 기술 스택, 과목, 연도, 주제 기반 검색 지원
- 자연어 질의를 통한 프로젝트 탐색
- RAG 기반 답변 생성 구조 설계

사용 기술 예시:

`Python` `FastAPI` `PostgreSQL` `OpenSearch` `RAG` `Embedding` `GitHub API`

---

### 산업 안전 보호구 착용 감지 시스템

건설 및 산업 현장에서 작업자의 안전모, 안전조끼 등 보호구 착용 여부를 탐지하는 컴퓨터 비전 기반 시스템을 개발했습니다.

주요 내용은 다음과 같습니다.

- YOLO 기반 객체 탐지 모델 학습
- 안전모, 조끼, 작업자, 미착용 상태 탐지
- 클래스별 성능 분석
- 낮은 성능을 보이는 클래스에 대한 데이터 품질 및 불균형 분석
- 현장 적용을 고려한 알림 및 기록 구조 검토

사용 기술 예시:

`Python` `Ultralytics YOLO` `OpenCV` `Computer Vision` `Dataset Preprocessing`

### GPU / NPU AI 추론 성능 분석

AI 모델이 실제 하드웨어에서 실행될 때 발생하는 성능 병목에 관심을 가지고 있습니다.

특히 다음 요소를 중점적으로 학습하고 있습니다.

- CUDA 실행 모델
- Grid, Block, Thread 구조
- Global Memory와 Shared Memory 차이
- CPU-GPU 데이터 전송 비용
- 병렬화 가능한 연산과 병목 구간 분석
- GPU/NPU 기반 LLM 추론 구조

관심 기술:

`CUDA` `GPU Computing` `NPU` `OpenVINO` `LLM Inference` `Performance Profiling`

## 학습 및 개발 방향

현재는 AI 모델 자체뿐만 아니라, AI 시스템이 실제 서비스로 연결되는 전체 흐름에 관심을 두고 있습니다.

특히 다음과 같은 질문을 중심으로 학습하고 있습니다.

- AI 모델의 성능은 실제 하드웨어에서 왜 이론 성능만큼 나오지 않는가?
- 데이터 품질과 클래스 불균형은 모델 성능에 어떤 영향을 주는가?
- RAG 시스템에서 검색 품질은 답변 품질에 어떻게 연결되는가?
- 사용자가 실제로 쓸 수 있는 AI 서비스 구조는 어떻게 설계해야 하는가?
